  <em>Bem-vindo(a) ao repositório da Oficina de Chat em Tempo Real! Este projeto contém todo o código-fonte e material de apoio utilizado durante a apresentação na ETEC.</em>
</p>

## 🎯 Objetivo da Oficina

O objetivo desta oficina é demonstrar de forma prática como construir uma aplicação de chat que funciona em tempo real. Os participantes aprenderão os conceitos fundamentais de WebSockets e como a biblioteca **Socket.IO** simplifica a comunicação bidirecional entre o cliente e o servidor, utilizando **Node.js** como base para o back-end.

---

## ✨ Funcionalidades do Projeto

O chat desenvolvido nesta oficina inclui as seguintes funcionalidades:

- **Conexão de Múltiplos Usuários:** Vários usuários podem se conectar simultaneamente.
- **Envio e Recebimento de Mensagens:** As mensagens são enviadas e aparecem instantaneamente para todos os participantes.
- **Notificações de Conexão:** O sistema avisa a todos quando um novo usuário entra na sala.
- **Notificações de Desconexão:** Todos são notificados quando um usuário sai do chat.
- **Interface Simples:** Um front-end básico em HTML, CSS e JavaScript para interagir com o servidor.

## 📦 Como Rodar o Projeto

Você pode clonar este repositório para executar a aplicação de chat na sua própria máquina e explorar o código.

#### Pré-requisitos:
- **Node.js** (v18 ou superior)
- **Git**

#### Passos para Instalação:

1.  **Clone o repositório:**
    ```bash
    git clone https://github.com/Ma2903/Oficina-ETEC.git
    cd Oficina-ETEC
    ```

2.  **Instale as dependências do servidor:**
    ```bash
    npm install
    ```

3.  **Inicie o servidor:**
    ```bash
    npm start
    ```
    *ou, se preferir, pode usar o `node` diretamente:*
    ```bash
    node index.js
    ```

4.  Abra seu navegador e acesse `http://localhost:3000`. Abra em múltiplas abas para simular vários usuários!
