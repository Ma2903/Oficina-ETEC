# Oficina ETEC

Este repositório contém um projeto demonstrativo de comunicação em tempo real utilizando **Socket.io** e **Node.js**. O objetivo é fornecer uma base sólida para desenvolvedores que desejam entender e implementar funcionalidades de comunicação instantânea em suas aplicações web.

## 📦 Tecnologias Utilizadas

- **Node.js**: Ambiente de execução JavaScript no servidor.
- **Socket.io**: Biblioteca para comunicação bidirecional em tempo real entre cliente e servidor.
- **Express**: Framework para construção de aplicações web em Node.js.
- **HTML/CSS/JavaScript**: Tecnologias básicas para construção da interface do usuário.

## 🚀 Como Executar o Projeto

1. **Clonar o repositório:**

   ```bash
   git clone https://github.com/Ma2903/Oficina-ETEC.git
   cd Oficina-ETEC
   
2. **Instalar as dependências:**

    ```bash
  npm install

3. **Iniciar o servidor:**

    ```bash
  node index.js

## 🌐 Acessar a aplicação:

Abra o navegador e vá para http://localhost:3000.

## 📚 Estrutura do Projeto
- index.js: Arquivo principal do servidor Node.js.
- package.json e package-lock.json: Gerenciamento de dependências do projeto.
- public/: Diretório contendo os arquivos estáticos da aplicação (HTML, CSS, JavaScript).
- Comunicação em Tempo Real com Socket.io e Node.js.pptx: Apresentação explicativa sobre o funcionamento do projeto.
